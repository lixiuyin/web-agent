**Figure 1 interpretation (from pdf_analyze_figure on page 2 of the downloaded PDF):**

Caption (verbatim source statement): "Figure 1: Qwen3.8-Flash-Next architecture. Token mixing alternates three GDN layers with one QSA layer per block of four. Every sublayer reads and writes through GR, which widens the residual stream and gates the read elementwise. An n-gram embedding layer at Layer 2 scales capacity off the accelerator via host-memory prefetching. The MTP module reuses QSA indices across speculative decoding steps."

- **Purpose:** Figure 1 is the whole-model architecture overview: it shows how input tokens flow through vocabulary embedding, the n-gram embedding layer, the repeated token-mixing/feed-forward blocks, and finally the prediction head plus MTP heads, making the four main design choices of Qwen3.8-Flash-Next legible at a glance.
- **Labels directly read in the diagram:** Input Tokens; Vocabulary Embedding; N-gram Embedding Layer (Layer 2 only); Hidden States; Expanded Residual; GR Read; GR Write; MoE; QSA Layer (Qwen Sparse Attn); GDN Layer (Gated DeltaNet); Prediction Head; MTP Modules.
- **Key architectural findings / design choices (caption-supported):**
  1. **Hybrid token mixing (3:1):** each block of four layers alternates three Gated DeltaNet (GDN) layers with one Qwen Sparse Attention (QSA) layer — a linear-recurrent/attention mix rather than uniform attention.
  2. **Gated Residual (GR) on every sublayer:** all sublayers read from and write to the residual stream through GR, which widens the residual stream (four branches) and applies an elementwise gate on the read, giving per-sublayer control of residual contributions.
  3. **Off-accelerator capacity scaling:** a single n-gram embedding layer placed at Layer 2 adds capacity held outside accelerator memory, brought in via host-memory prefetching — capacity grows without adding backbone compute.
  4. **Speculative decoding reuse:** the MTP (Multi-Token Prediction) module reuses the QSA indices across speculative decoding steps, so draft/verify steps share the sparse-attention index work.
  5. **MoE feed-forward blocks** appear as the sublayer paired with token mixing in each block.
- **Efficiency figures stated in the report text (not readable from the diagram's visual proportions):** 125B total parameters with ~6B activated per token, the Layer-2 n-gram table contributing ~51B parameters kept off the accelerator, QSA compressing the key sequence to reduce indexer cost from O(n²) to O(n²/r), GDN keeping a fixed-size recurrent state to limit decode-time memory traffic, and a reported ~1/9 training-FLOPs figure.
- **Caveats:** Figure 1 contains no plots, curves or unlabeled data points, so no quantitative trend can be estimated from it; the component labels above are what is visibly painted, the four design claims come from the caption/body text, and adjacency of blocks in the diagram should not be read as a strict serial arrow chain beyond the embedding → blocks → head flow the figure depicts.
