The official Git manual is hosted at git-scm.com (the official Git project site). The git(1) command documentation page is https://git-scm.com/docs/git, and its SYNOPSIS section is at https://git-scm.com/docs/git#_synopsis.

Git command synopsis (as extracted from the official page):

git [-v | --version] [-h | --help] [-C <path>] [-c <name>=<value>]
    [--exec-path[=<path>]] [--html-path] [--man-path] [--info-path]
    [-p | --paginate | -P | --no-pager] [--no-replace-objects] [--no-lazy-fetch]
    [--no-optional-locks] [--no-advice] [--bare] [--git-dir=<path>]
    [--work-tree=<path>] [--namespace=<name>] [--config-env=<name>=<envvar>]
    <command> [<args>]
