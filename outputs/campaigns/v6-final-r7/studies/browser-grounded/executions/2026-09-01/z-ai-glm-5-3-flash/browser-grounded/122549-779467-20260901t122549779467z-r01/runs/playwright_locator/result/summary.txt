Role of Playwright locators: According to the official Playwright Python API reference, 'Locators are the central piece of Playwright's auto-waiting and retry-ability. In a nutshell, locators represent a way to find element(s) on the page at any moment.' A locator is created with the page.locator() method. Because locators are resolved lazily against the live DOM, they auto-wait for elements to appear/become actionable and retry automatically, making tests resilient to timing issues. The Locator class also exposes methods such as all() (added in v1.29), which returns an array of locators when the locator points to a list of elements. Exact API URL cited: https://playwright.dev/python/docs/api/class-locator (page title: 'Locator | Playwright Python').
