The Playwright Page class (Python API) provides methods to interact with a single tab in a Browser, or an extension background page in Chromium. One Browser instance might have multiple Page instances. The docs include an example that creates a page, navigates it to a URL, and saves a screenshot (available in both sync and async API styles). Source: https://playwright.dev/python/docs/api/class-page (page title: "Page | Playwright Python").
