GitHub Docs page "About authentication to GitHub" (exact URL: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-authentication-to-github) summarizes GitHub's authentication guidance as follows:

- GitHub authentication verifies your identity so your account and data stay secure. You authenticate in several ways depending on context:
  - **Browser (github.com):** sign in with your username/password; if two-factor authentication (2FA) is enabled, you also provide a second factor (e.g., a code from an authenticator app, SMS, security key, or GitHub Mobile passcode).
  - **Command line (Git operations):** use HTTPS with a personal access token (classic or fine-grained) instead of your password, or authenticate over SSH using an SSH key; GitHub CLI and credential managers can help manage these credentials.
  - **GitHub Desktop:** authenticate to GitHub through the desktop client, which handles credentials for you.
  - **API / GitHub Actions workflows:** use GITHUB_TOKEN (the automatically provided Actions token) to authenticate to the API within workflows, rather than personal credentials.
  - **GitHub Apps:** authenticate as an app (with installation tokens) to act on behalf of the app rather than a user.
- The Docs strongly recommend enabling 2FA and keeping account-and-data-secure practices (strong credentials, secure keys/tokens) as core to protecting your account.
