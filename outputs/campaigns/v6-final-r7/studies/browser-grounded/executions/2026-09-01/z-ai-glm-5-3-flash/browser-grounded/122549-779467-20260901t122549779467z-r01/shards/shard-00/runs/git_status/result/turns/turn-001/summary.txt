Git's official manual (https://git-scm.com/docs/git-status) explains that `git status` shows the working tree status. Specifically, it displays paths that have differences between the index file and the current HEAD commit (staged changes — what you would commit by running `git commit`), paths that have differences between the working tree and the index file (unstaged modifications), and paths in the working tree that are not tracked by Git and are not ignored by gitignore (untracked files). Synopsis: `git status [<options>] [--] [<pathspec>…​]`. Exact official manual URL: https://git-scm.com/docs/git-status
