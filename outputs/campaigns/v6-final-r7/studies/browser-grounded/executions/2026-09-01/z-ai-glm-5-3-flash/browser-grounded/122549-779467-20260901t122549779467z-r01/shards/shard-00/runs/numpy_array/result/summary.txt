numpy.array creates a new ndarray — NumPy's N-dimensional array object — from an array-like input such as a list, tuple, or nested sequence. Per the official NumPy reference page (NumPy v2.5 Manual), the signature is numpy.array(object, dtype=None, *, copy=True, order='K', subok=False, ndmin=0, like=None), and it returns an ndarray constructed from the given object. Key behaviors: by default (copy=True) it makes a copy of the input; the dtype is inferred from the input data unless explicitly specified; order controls memory layout ('K', 'A', 'C', 'F'); ndmin specifies a minimum number of dimensions; and subok allows passing through subclasses.
