JavaScript is a lightweight, interpreted (just-in-time compiled) programming language with first-class functions. While best known as the scripting language for web pages, many non-browser environments also use it, such as Node.js, Apache CouchDB, and Adobe Acrobat. JavaScript is a prototype-based, multi-paradigm, single-threaded, dynamic language, supporting object-oriented, imperative, and declarative (e.g., functional programming) styles. MDN's JavaScript section provides a reference, guide, and resources covering the language core (ECMAScript), including standard built-in objects, statements, expressions and operators, functions, classes, promises, typed arrays, iterators and generators, and client-side web APIs.
