Effective Go (https://go.dev/doc/effective_go) is the official Go documentation guide that explains how to write idiomatic, effective Go code. Its stated purpose (from the Introduction): because Go focuses on simplicity, reliability, and efficiency and has unusual properties that make effective Go programs differ in character from programs in related languages like C++ or Java, a straightforward translation of such a program into Go is unlikely to be satisfactory. The document therefore teaches Go programmers how to use the language well—covering topics such as formatting, commentary, names, control structures, functions, data (slices, maps, allocation), initialization, methods, interfaces, embedding, concurrency, errors, and examples—so that programs feel properly Go-like rather than transliterated from other languages. Exact URL: https://go.dev/doc/effective_go (page title: "Effective Go - The Go Programming Language").
