According to its official documentation page (https://docs.python.org/3/library/asyncio.html), asyncio is "a library to write concurrent code using the async/await syntax." It is used as a foundation for multiple Python asynchronous frameworks that provide high-performance network and web servers, database connection libraries, distributed task queues, etc., and it is often a perfect fit for IO-bound and high-level structured network code. asyncio provides both high-level APIs (coroutines, tasks, streams, synchronization primitives, subprocesses, etc.) and low-level APIs (event loop, futures, transports and protocols) for building asynchronous applications, plus introspection/debugging tooling.
