According to the official Git manual (https://git-scm.com/docs/git-clone), the DESCRIPTION section states: "Clones a repository into a newly created directory, creates remote-tracking branches for each branch in the cloned repository (visible using git branch --remotes), and creates and checks out an initial branch that is forked from the cloned repository's currently active branch." It further notes that after the clone, a plain `git fetch` without arguments updates all the remote-tracking branches, and a `git pull` without arguments will in addition merge the remote branch into the current branch (configuring remote.origin.url and remote.origin.fetch as needed). In short, git clone copies an existing repository into a new directory, sets up remote-tracking branches, and checks out an initial branch based on the source repository's active branch. Exact URL cited: https://git-scm.com/docs/git-clone
