JavaScript — description as published by MDN (developer.mozilla.org)

MDN's definition (verbatim from the page's opening paragraphs):
"JavaScript (JS) is a lightweight interpreted (or just-in-time compiled) programming language with first-class functions. While it is most well-known as the scripting language for Web pages, many non-browser environments also use it, such as Node.js, Apache CouchDB and Adobe Acrobat. JavaScript is a prototype-based, garbage-collected, dynamic language, supporting multiple paradigms such as imperative, functional, and object-oriented."

Key points MDN makes about the language:
- Lightweight, interpreted / just-in-time (JIT) compiled language.
- Has first-class functions (functions are ordinary values that can be passed, returned and stored).
- Best known as the scripting language of Web pages, but also runs outside browsers — e.g. Node.js, Apache CouchDB, Adobe Acrobat.
- Prototype-based (inheritance via the prototype chain rather than classical classes), garbage-collected, and dynamically typed.
- Multi-paradigm: supports imperative, functional and object-oriented styles.
