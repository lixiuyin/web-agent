Evidence from the page (section "pandas data table representation", the first content section after the tutorial's intro):
- The tutorial builds a table of Titanic passenger data with the example code `df = pd.DataFrame({"Name": [...], "Age": [22, 35, 58], "Sex": [...]})`, i.e. a **2-dimensional, labeled, size-mutable, potentially heterogeneous tabular data structure** made of **rows and columns** (here: columns `Name`, `Age`, `Sex`; one row per passenger; each column holding a different data type — text, integers, categorical).
- It stresses that pandas is **table-oriented**: all data is stored and manipulated as (labeled columns and rows of) a `DataFrame`, and you can inspect it with `df.head()`, `df.tail()`, `df.info()`, `df["Age"]`, `df.mean(numeric_only=True)`, etc. Selecting a single column yields a one-dimensional labeled array (a pandas `Series`), and the tutorial's closing "Things you have learned" bullets are all about creating/inspecting this tabular `DataFrame` and its summary statistics.
